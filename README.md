## iPhone/iOS 端注册教程
### 步骤1：打开Telegram应用
在App Store下载Telegram，点击应用图标启动。
![iOS打开Telegram](https://media.geeksforgeeks.org/wp-content/uploads/20231016204153/IMG_20231016_203740.jpg)

### 步骤2：开始注册流程
点击「开始发送消息」按钮，进入验证环节。
![开始注册](https://media.geeksforgeeks.org/wp-content/uploads/20231016204442/IMG_20231016_202828.jpg)

### 步骤3：手机号验证
选择对应国家/地区（如中国+86），输入手机号，点击「继续」；接收并输入OTP验证码完成验证。
![输入手机号](https://media.geeksforgeeks.org/wp-content/uploads/20240924103100/EnterMobileNumberandClickContinue.webp)

### 步骤4：完成账户创建
输入个人姓名（可选），即可完成Telegram账户创建。

## 无手机号注册Telegram（5种合规方法）
> 注：以下方法仅用于技术学习，部分虚拟号可能被Telegram限制，优先选择正规付费服务商。

### 方法1：虚拟手机号（VoIP）
1. 注册Google Voice、TextNow等合规VoIP服务，获取虚拟号码
2. Telegram注册时输入该虚拟号码
3. 接收验证码完成验证即可

### 方法2：一次性预付费SIM卡
1. 购买无需实名的预付费SIM卡
2. 插入手机接收Telegram验证码
3. 完成注册后可移除SIM卡

### 方法3：固定电话验证
1. 注册时输入固定电话号码
2. 等待短信验证失败后，选择「呼叫我」选项
3. 接听来电获取验证码，输入完成注册

### 方法4：专用线上注册SIM卡
购买低成本预付费SIM卡，专门用于线上平台注册，保护个人隐私号码。

### 方法5：Google Voice（美国用户专属）
1. 注册Google Voice获取美国号码
2. 使用该号码完成Telegram注册验证

## 同一手机号创建新账户/多账户切换
### 方法1：删除旧账户后重建
1. 访问Telegram停用页面：https://my.telegram.org/auth
2. 输入手机号验证后，注销原有账户（数据会清空）
3. 重新打开Telegram，使用同一手机号注册新账户

### 方法2：多账户切换（需不同手机号）
1. 打开Telegram → 左上角菜单 → 点击当前手机号
2. 选择「添加账户」，输入新手机号完成注册
3. 点击手机号即可自由切换多个账户

## 账户退出登录教程
1. 打开Telegram，点击左上角三条杠菜单
2. 选择「设置」→ 点击右上角三个点
3. 选择「注销」→ 确认点击「注销」即可退出账户

## 常见问题FAQ
### Q1：可以用邮箱注册Telegram吗？
A：不可以，Telegram仅支持手机号作为核心验证方式，邮箱仅用于辅助账户找回。

### Q2：一个手机号可以创建多个Telegram账户吗？
A：不可以，Telegram限制每个手机号仅绑定一个账户；多账户需使用不同手机号。

### Q3：虚拟手机号注册安全吗？
A：选择正规付费VoIP服务商（如Google Voice）相对安全，免费虚拟号存在信息泄露风险。

### Q4：Telegram可以更换绑定手机号吗？
A：可以，在设置中可更换绑定手机号，不会丢失聊天记录和联系人。
